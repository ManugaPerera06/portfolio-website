# Manuga Perera - Personal Portfolio

A personal developer portfolio built to showcase my skills, projects and experience.

## 🔗 Live Demo
https://manuga-perera-dev.vercel.app

## 🚀 Features
- Fully responsive design
- Dedicative Project and Skills sections
- Smooth UI/UX

## 📌 Portfolio Sections

* **About Me** – A brief introduction highlighting my background as a Software Engineering undergraduate, career aspirations, and engineering focus.
* **Experience** – Overview of my professional journey and hands-on development work.
* **Skills** – Categorized display of technical proficiencies across frontend, backend, tools, and frameworks.
* **Projects** – Highlights of key software projects, featuring full-stack applications and machine learning implementations with direct source code and demo links.
* **Education** – Showcasing my academic background.
* **Contact** – Interactive form and direct links to connect via email, GitHub, and LinkedIn.
